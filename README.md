# VANYA Handlooms 🥻✨
> **Authentic Handcrafted Indian Sarees & Pure Silks**

Welcome to the official repository for **VANYA Handlooms** — an e-commerce boutique celebrating traditional Indian weaves, Kerala Kasavu, temple borders, pure silks, and bridal collections.

---

## 🌟 Key Features

- **Responsive Modern UI**: Luxury boutique aesthetic optimized for mobile, tablet, and desktop devices.
- **Product Catalog & Filtering**: Seamless category tabs (Kerala Handloom, Silk Collection, Golden Zari, Bridal).
- **Interactive Cart & Wishlist**: Real-time state persistence with slide-out sidebars.
- **Supabase Integration**: Real-time inventory and catalog management.
- **WhatsApp Direct Checkout**: One-click instant ordering directly to the boutique via WhatsApp.
- **SEO & Structured Data**: Built-in Schema.org metadata, Open Graph cards, sitemap, and robots.txt.
- **Vercel Ready**: Preconfigured with `vercel.json` for clean routing and ultra-fast static hosting.

---

## 📂 Project Structure

```
├── Images/               # Boutique brand assets and product photography
├── collection.html       # Full saree catalog & collections page
├── index.html            # Boutique landing page & featured collections
├── package.json          # Project manifest & metadata
├── robots.txt            # Search engine crawler policies
├── script.js             # Cart, search, modal & dynamic UI logic
├── sitemap.xml           # SEO sitemap
├── style.css             # Premium custom stylesheet & responsive styles
├── supabase-config.js    # Supabase credentials & WhatsApp configuration
└── vercel.json           # Vercel deployment configuration
```

---

## 🚀 Deployment on Vercel

This website is ready for 1-click deployment on [Vercel](https://vercel.com):

1. Import this repository into Vercel via **Add New Project**.
2. Framework Preset: **Other**.
3. Click **Deploy**.
